# Tiny Launch Machine — logo rules (final, 4 Nov 2026)

**Main logo (A, "scale"):** small "tiny" (Inter Bold) above big "LAUNCH / MACHINE" (Archivo Black), with one round dot after MACHINE. The joke is the scale: "tiny" is tiny.
**Icon:** "TLM" + dot in a black square. Use where the main logo would be too small.

| File | Use it for |
|---|---|
| logo-on-dark-transparent.svg / .png | Website header & footer on dark sections, videos |
| logo-on-light-transparent.svg / .png | Website header on paper background, documents |
| logo-on-ink-bg / logo-on-paper-bg | LinkedIn banner, decks, PDFs (background baked in) |
| monogram-favicon.svg / .png, favicon.ico, favicon-32.png | Browser tab icon |
| apple-touch-icon-180.png | iPhone home-screen icon |
| profile-picture-1080.png | Instagram, LinkedIn page, WhatsApp display picture |
| og-image-1200x630.png | Link preview when the site is shared |

## Rules
- Dot colour: **lemon #F5C518 on dark**, **sea blue #0B3C5D on light**. Never lemon on the paper background (too faint).
- Text colour: white on dark, ink #111111 on light. No other colours, no gradients, no shadows, no outlines.
- Keep empty space around the logo at least the height of the word "tiny".
- Don't stretch, rotate, re-type or change the letter spacing. Use the SVG files (letters are already shapes).
- Minimum width of main logo: 120px on screen. Smaller than that → use the TLM icon.
